# Lucide icons

These vector files are unmodified source assets from Lucide 0.468.0:
https://github.com/lucide-icons/lucide/tree/0.468.0/icons

License: ISC, included in LICENSE.txt. The generic renderer uses their original geometry for interface actions. The current H-node app/tray PNG, ICO and macOS ICNS are an original project mark generated by `scripts/generate-brand-icons.py`, separate from this Lucide set.

The code uses an opaque surface and does not animate, so reducing transparency/motion does not remove information.
