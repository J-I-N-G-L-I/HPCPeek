# HPCPeek：使用真实 Aire / Calder 账号的最短验收

下面的真实服务验证需要你自己的学校账号。本项目不包含 AIRE 密码、Duo 会话、管理员提供的指纹或真实节点快照；离线模拟不能替代这些检查。请使用现有测试作业，不需要为了验收提交或取消生产作业。v1.0.0 界面默认为英语，步骤引用实际按钮名。

## 1. 双重 Duo 与连接复用（约 3 分钟）

**v1.0.0 关键回归：先 Calder，后 Aire。** 首先连接 Calder 并完成服务器要求的全部验证；保持它在线，在展开页选择 **Connect to Aire**，核对 Aire 和网关参数后主动连接。新指纹须通过可信渠道核对。预期普通密码成功后继续该主机的额外验证，而不是因密码与 keyboard-interactive 的顺序提前失败；两边都连接后，切换及刷新不应重新登录。实际需要几次 Duo 由学校策略决定，一次网关批准不等于目标机也已完成。两边应保留独立作业与节点数据。

若服务器仍拒绝连接，记录界面指出的主机与认证阶段，先核对已有终端会话和学校账户状态，不连续尝试猜测密码。不要记录或提交密码、验证码或 Duo 回答。本机回环可复现旧版的认证顺序问题并验证修复，但不能代替本步骤的真实账号确认。

用户已确认此前的网关 + AIRE 登录成功；本版保留独立的 Aire / Calder 会话与显示，复用已有 SSH.NET 认证实现和 v0.3.0 可选密码复用。此前成功不等于 Calder 已实测。以下步骤仍用于真实服务器回归。相同用户名且确实使用同一密码时，可勾选 **Use one password for both hosts** 后主动连接：普通密码最多复用一次，两处 Duo 仍需按服务器要求分别完成。语义不明的提示仍可能再次要求密码。该新增路径目前只经过模拟 / 本机协议验证，学校真实策略需要此次复验。

1. 首次向导右上角直接选择 Aire / Calder。核对用户提供的默认主机 `aire.leeds.ac.uk` / `calder.leeds.ac.uk`、可选网关 `rash.leeds.ac.uk` 与端口22；用已有 MobaXterm 会话确认并填写用户名。已有保存值不得被默认值覆盖。分别从可信渠道核对首次显示的 SHA-256 指纹。
2. 在网关提示中按服务器实际选项完成 Duo；接着完成 AIRE 目标机的验证。记录两处主机名及认证是否成功，**不要记录密码、验证码或回答**。
3. 成功后展开 / 收起两次，手动刷新一次，等待冷却后再次刷新。预期没有新密码或 Duo 提示。若只要求一处 Duo，核实该账号 / 网络的服务器策略，不把缺少第二次提示视为应用失败。
4. 暂时断开 VPN 或使电脑休眠再唤醒。预期保留旧快照、时间不伪装成新数据，不自动重新弹认证。主动选择 **More → Reconnect…**，按需验证；已有运行作业不应再次触发开始运行通知。

认证后在 Settings → Connection 选择 Calder 并编辑其连接，或在连接向导右上角切换到 Calder；核对默认地址后主动完成对应认证。切换到尚未连接的集群不应自动发起认证。两边都成功后反复切换集群 / GPU 型号，应自动在各自已认证会话查询而不重登；让一边断线，另一边仍可刷新。同名 Job ID / 节点不应混用快照或通知。

## 2. 可选本机密码记住（约 2 分钟）

保持默认 **Password storage → This connection** 连接一次，退出重开后普通密码仍需输入。再主动选择 **Remember on this device** 并完成认证；下次仍主动 Connect，明确普通密码可由操作系统凭据库提供，Duo 按服务器要求继续出现。不要在验收记录中写入密码、验证码或具体回答。

Windows 保存到当前用户的 Credential Manager，Mac 保存到 Keychain；`portable-data` / Application Support 配置只含 Remember 偏好，不含密码。分别确认网关与目标按真实主机、端口、账号区分；更换目标或用户名不应误用旧目标密码。同一网关 / 账号可共用保存项，但两个集群仍分别建立会话。

在 **Settings → Connection** 选中一个集群后点 **Forget saved passwords**：当前连接应保持，下一次认证再要求对应普通密码。若两个集群共用网关，删除共享网关项后另一边下次也可能重新询问。不要故意输入错误生产密码来测试锁定策略；保存值失效与安全失败路径通过本机模拟验证。Mac Keychain 原生读写删除仍需 Mac 实机确认。

## 3. 核对个人队列（每个集群约 1 分钟）

分别在你已有的 Aire / Calder 终端中运行同一只读命令，并将应用详情切到相同集群：

```sh
LC_ALL=C squeue --me --array --noheader --format='%i|%j|%T|%M|%l|%N|%r'
```

在相近时间选择 **Refresh now**，对照 **My jobs** 的 Job ID（含数组任务 / 范围）、名称、状态、已用时间、时限、节点和等待原因。两次采样间作业可能变化，以各自采样时间为准。空队列应该明确显示无作业与成功采样时间，而不是连接错误。展开一个正在 RUNNING 的作业，观察带 `~` 的用时每秒增加，但顶部 Jobs 采样年龄仍正常增长、没有新认证。下次队列采样应校准；断线或采样过期时应停止本地推算，明确回到最后采样值。排队、完成中和结束状态不应继续增加。

可等待一个已有排队作业开跑，确认只收到一次运行通知。作业退出队列后，对照以下命令（将 `JOB_ID` 换成实际 ID，保留数组任务后缀）：

```sh
LC_ALL=C sacct --array --noheader --parsable2 --allocations --jobs='JOB_ID' --format=JobID%128,State%64,ExitCode
```

历史暂不可见时应显示待确认。分别确认完成、失败、超时的实际反馈；**Settings → Notifications** 关闭后应不再弹出。当前通知是应用桌面浮层，不进入系统通知中心；检查 8 秒关闭、手动消除和不抢焦点。

## 4. 核对同节点 GPU（每个集群约 2 分钟）

```sh
scontrol -o -d show nodes
```

在相近时间刷新 GPU，选当前集群的可见型号；没有 Need / 每节点需求选择器，直接核对节点剩余整卡。矩阵中每格代表一个真实节点，数字是剩余整卡，颜色不是利用率；只要有可用整卡就统一绿色，Unavailable / Unknown 仍保留。Calder 的实际节点剩余可达到 8，不应按 Aire 的 3 卡物理配置截断。悬停或点击一两个具体节点，核对其 `NodeName`、`State`、`CfgTRES/AllocTRES` 或 `Gres/GresUsed`：

- 同一真实节点即使出现在多个分区也只统计一次。
- 分型号 `gres/gpu:型号` 不再加上通用 `gres/gpu`。
- 对候选范围内的已知整卡数据，未分配 = 配置 − 已分配；单节点最多可用取剩余数最大值，不是配置上限。Calder 配置 8 / 已分配 5 时应显示剩余 3。
- Calder 未采样时默认只有 H200 NVL；采样后以该集群实际型号为准，不从其他集群或旧偏好带入 L40。
- `MIXED` 仍可能有候选容量；`DOWN` / `DRAIN` / 维护节点单列并排除。
- 两个节点各剩 1 张同型号卡时，总未分配 2，单节点最多 1，同节点双卡候选 0。
- 型号不明、缺少分配字段、权限限制或 MIG / 共享资源应显示未知或部分可见，不能推断为完全空闲。

若 `scontrol` 被禁止，确认 GPU 显示失败 / 旧采样时间，同时个人队列仍正常更新。应用显示的是当前账号能看见的范围，不能与管理员视角的全站容量直接比较。候选节点不承诺作业立即启动。

## 5. Windows 实机补充检查

正常启动时，即使已有配置，也应打开屏幕中央的、可直接切换集群且全部字段可编辑的连接向导；From MobaXterm 只展开参数查找说明，登录与设置中均不出现 Demo 按钮。认证提示也应居中；打开 / 关闭对话框不得移动悬浮窗，成功后恢复紧凑窗。登录后无需退出应用即可通过设置重新编辑主机、端口、用户名和网关；Reconnect 同样先显示预填表单，不静默认证。

在设置检查默认 5 分钟刷新，改为另一个预设或自定义秒数后观察实际队列 / GPU 查询时间变化；保存不应再次要求密码或 Duo。紧凑窗同时显示 Aire / Calder 小图，展开有集群 / GPU 型号切换且没有 Need 选择器；紧凑矩阵只显示颜色，展开与悬停可核对完整节点信息。连接圆点表达当前选中集群的账号登录：Aire 已登录而 Calder 未登录时，切换到 Calder 应是红点，切回 Aire 应是绿点。Demo 不代表真实账号登录。检查圆点与名称的视觉水平对齐；刷新时间和旧快照不得冒充当前空闲。

在 Windows 显示设置分别使用 125%、150%、200% 缩放，确认紧凑双集群小图、操作按钮和展开内容没有裁切。跨不同缩放显示器拖动，再收起、展开；刷新时窗口不移动或抢焦点。退出重开，确认位置和所选型号保留。应用开着时退出浏览器、终端、MobaXterm，确认仍能刷新。

从托盘唤回，取消图钉后点到别处应隐藏，隐藏期间继续采样。检查 More 与作业行右键菜单、Tab、Escape、Ctrl+R / Ctrl+, / Ctrl+Q，以及系统高对比度和 Narrator 可读性。

## 6. 两种 macOS 架构分别补充检查

分别在 Apple Silicon 与 Intel 的 macOS 15+ 解压各自 ZIP，启动完整 `.app`；不能用 Windows 交叉编译或 Rosetta 结果替代两端原生结果。未签名包只记录开发测试状态；正式下载体验要使用 Developer ID 签名、公证和装订后的包，确认 Gatekeeper 放行，不关闭系统安全机制。

检查新版 H 节点应用 / 菜单栏图标、固定 / 临时面板切换、菜单和作业右键、Command 快捷键、浅 / 深色、系统减少透明度 / 动态效果、VoiceOver 和 Retina / 外接显示器。确认配置写 Application Support/HPCPeek，旧 AirePeek / AIRE Peek 配置仅在新文件缺失时迁移且保留指纹，移动 `.app` 后配置保留，非敏感导入 / 导出不修改主机信任；关闭面板继续采样，Quit 才退出。运行本仓库 `benchmark-portable.ps1` 留下该机启动与 RSS 数据。没有实际 Mac 时，以上逐项标“未实测”。
