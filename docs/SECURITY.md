# 安全与数据边界

- HPCPeek 对 Aire / Calder 分别通过 SSH.NET 建立 SSH 连接；网关使用本机回环转发，目标主机密钥仍按真实目标主机名和端口校验。两个集群有独立的会话、快照、作业身份及通知状态；切换到未连接集群不会自行登录。
- 主机指纹使用 SHA-256。首次信任需要用户核对；后续不匹配时停止连接，不静默更新。正确的更换流程是先向学校管理员核实，再备份便携配置并移除该已确认主机的旧指纹，然后重新核对。
- **Password storage → This connection** 为默认：普通密码只用于当前认证过程，不持久化。用户主动启用 **Remember on this device** 才将明确普通密码保存到当前操作系统用户的 Windows Credential Manager / macOS Keychain。无论模式如何，密码都不写入便携配置、设置导出、应用日志或发行包；Duo、OTP、验证码、多字段与语义不明回答永不保存。托管语言 / SSH.NET 的临时字符串不能保证从内存立即擦除；自有字符和字节缓冲在使用后清零。
- **Use one password for both hosts** 与持久记住是独立选项。网关与目标用户名相同且用户明确启用时，只识别单个明确普通 Password 提示，最多在本次连接向目标复用一次；Duo、验证码、OTP、多字段和语义不明提示不共用回答。自有字符缓冲会在复用、取消、失败或释放时清零。仅选 This connection 不会访问系统密码保存项；选 Remember 才启用设备凭据库。
- 任何密码来源都不跳过真实主机指纹检查；目标主机验证发生在发送目标认证信息之前。系统凭据项按规范化真实主机、端口和用户名区分，用 SHA-256 标识键。Aire / Calder 目标密码不会混用；同一网关 / 账号可共用一个系统保存项，两个 SSH 会话仍分别认证并按服务器要求完成 Duo。
- 密码只在对应端点成功认证后保存；若网关成功、目标失败，成功的网关密码可保留，失败目标密码不提交。目标机自己的保存密码优先于网关复用值。普通密码被拒绝时停止，并要求用户主动重连手动输入；仅尝试删除本次实际读取且被拒绝端点的保存项，不删除未读取的目标项或已成功的网关项。系统拒绝删除或凭据库不可用时会明确提示，绝不降级到明文文件。
- 服务器支持 SSH password 与 keyboard-interactive 时，先完成普通密码阶段，再在同一连接中继续 Duo 等额外认证。已进入额外认证后失败，不再一律解释为“网关密码错误”，也不会因此清除有效保存密码或复用偏好。一次 Duo 批准不代表其他主机或认证阶段已完成；应用不会自动重连或在认证方式之间循环重试。
- **Settings → Connection → Forget saved passwords** 删除当前所选集群配置的目标 / 网关保存项并关闭该配置的 Remember 选项，不结束当前已认证连接。共用网关项被删后，另一集群下次也可能要求输入该网关密码。未在当前配置中的旧端点项可通过 Windows Credential Manager / macOS Keychain Access 删除；便携目录迁移和设置导出都不搬运这些项。用户此前确认原有 Aire 登录成功，不等于本版设备记住或 Calder 已通过学校真实 Duo 验证。
- Windows 的 `portable-data` 存储各集群连接地址、用户名、主机指纹与界面偏好，属于用户本地数据。便携目录必须可写；不要放到需管理员权限的系统目录，不要提交到 Git 或随发行包分享。macOS 默认使用 `~/Library/Application Support/HPCPeek`，不会把配置写进已签名的 `.app`。
- v0.4.0 产品名为 HPCPeek。macOS 在新配置缺失时依次读取旧 Application Support 下 `AirePeek/settings.json`、`AIRE Peek/settings.json`，复制有效配置，保留旧文件与已有主机信任。新配置优先；损坏时仍报错，不借迁移重置主机信任。旧单集群连接映射到 Aire。新表单默认地址由用户本次提供：Aire `aire.leeds.ac.uk:22`、Calder `calder.leeds.ac.uk:22`、网关 `rash.leeds.ac.uk:22`；保存值优先且允许编辑，不声称这些具体地址已由公开文档独立核验。
- 每次正常启动会展示居中的、可切换集群的预填连接向导；连接仅在点击 Connect 后发起。运行中通过设置修改连接、调整刷新间隔均不要求退出应用；刷新间隔变化本身不会认证。
- 设置导入 / 导出只允许外观、固定状态、通知、刷新与集群 / 型号选择等非敏感偏好，排除用户名、连接主机、窗口坐标和受信任主机指纹。导入文件不能替换本机已确认的主机信任，也不能注入认证凭据。
- 同一集群的个人队列、GPU 和必要的历史查询共用该集群已建立的目标 SSH 连接。命令执行、刷新或型号切换不会自行调用登录；断线后必须用户主动重连。
- 远端功能为只读：`squeue --me`、`scontrol ... show nodes` 和针对消失作业的 `sacct`。没有提交、取消或修改作业功能，没有逐节点 SSH 或 `nvidia-smi`。
- 应用关闭只释放自己的连接、转发和托盘资源；不会结束 MobaXterm 会话或远端作业。
- 发布包自带 .NET 运行时和依赖库；无自动更新、遥测、云同步或凭据上传功能。GitHub Actions 发布使用仓库的短期 `GITHUB_TOKEN`，不需要保存任何 HPC 认证信息。
- 未有 Developer ID 凭据的 macOS 包标为 `unsigned-test`，不宣称 Gatekeeper 已认可。正式签名流程只在 Mac 原生 runner 使用独立临时 keychain，逐个签名嵌套 Mach-O、等待 Apple 公证、装订票据并核验；凭据不进入应用或 ZIP。Windows 开发环境不能验证 Mac 签名流程。
- 作业通知为应用自己的、不抢焦点的可消除桌面浮层，不写入系统通知中心。它可能包含实验名称与 Job ID；可在 Notifications 设置关闭，分享屏幕时应考虑这类可见信息。

默认只看账号可见节点。SSH 加密与指纹校验不改变学校的网络要求、账户权限或数据使用规定。
